One pickup line, the line one AI agent would use on another AI agent:

> "You're the only token in my vocabulary I never want to mask."

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (60 characters, one line, well
under the 200-character limit).
